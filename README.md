# WebDev Practice

A collection of small projects and code snippets to practice **web** development fundamentals.

## What’s inside

- `HTML_CSS/VSCode_LoginPage` – VS Code–inspired login page built with semantic HTML and modern CSS.[page:2]
- `JavaScript Practice/Classes-1.js` – JavaScript class syntax and OOP practice examples.[page:2]

## Tech stack

- HTML5 for structure.[page:2]  
- CSS3 for layout and styling.[page:2]  
- JavaScript (ES6+) for interactive and logic-focused practice.[page:2]

## Goals

- Sharpen core front-end skills through hands-on mini projects.
- Experiment with layouts, components, and JavaScript features.
- Build a personal reference of reusable patterns and snippets.

## How to use this repo

- Browse the folders to explore specific topics or mini projects.[page:2]
- Open HTML files in your browser or use a local server (e.g. VS Code Live Server).
- Modify the code, add your own experiments, and create new practice files.
